# Photos

Drop images here with these names (.jpg, .jpeg, .png, .webp or .avif). They
show up automatically at build time. Until then a placeholder is shown.
In `npm run dev` each placeholder is labelled with the filename it wants.
To replace a photo, overwrite the file with the same name.

Aim for about 2400px wide for heroes, 1200px for everything else. Keep files under 500 KB.

| File               | Where it shows                     | Current image (from old site)              |
|--------------------|------------------------------------|--------------------------------------------|
| hero               | Home page, top banner              | Crucifix on open Bible (Pexels stock)      |
| tile-about         | Home "Who We Are" card             | Christ icon banner (old site header)       |
| tile-worship       | Home "Our Worship Services" card   | Altar crucifix (Pexels stock)              |
| tile-resources     | Home "Resources" card              | Crucifix on open Bible (Pexels stock)      |
| hero-about         | About page banner                  | Christ icon banner (low-res, 595px)        |
| hero-worship       | Worship page banner                | Altar crucifix (Pexels stock)              |
| about-church       | About page, beside the intro       | (empty, needs a real photo of the parish)  |
| hero-new-here      | New Here page banner               | (empty)                                    |
| clergy-fr-dave     | Clergy page portrait (4:5)         | (empty)                                    |
| worship-livestream | Worship page, livestream section   | (empty)                                    |

Logos and resource thumbnails from the old site live in `public/images/`.
