# Parish photo library

Not served by the website. This is the organized, compressed set of parish photos.
Photos actually shown on the site are copied into `public/photos/` under slot names
(see `public/photos/README.md`).

- `library/`: compressed (max 2000px, ~78% JPEG) with all metadata (including GPS location) removed.
- `originals/`: full-size uploads, renamed. **Kept on this computer only** (in `.gitignore`).
